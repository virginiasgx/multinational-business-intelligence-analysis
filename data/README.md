
# Data Documentation

## Data Source

The data used in this project comes from the **Multinational Revenue, Employment, and Investment Database (MREID)**, provided by the U.S. International Trade Commission (USITC).

The database contains information about multinational enterprise activity across different countries, economic sectors, and years.

## Data Description

The dataset includes information about:

- **Countries:** Country of origin and destination of multinational subsidiaries.
- **Industries:** Economic sectors in which multinational enterprises operate.
- **Years:** Annual observations covering different periods.
- **Subsidiaries:** Number of multinational subsidiaries.
- **Operating Revenue:** Revenue generated by subsidiaries, expressed in thousands of US dollars.
- **Employment:** Number of employees.
- **Total Assets:** Total assets of subsidiaries, expressed in thousands of US dollars.

## Main Variables

| Variable | Description |
|---|---|
| `iso3_o` | Country of origin (ISO 3-letter code) |
| `iso3_d` | Destination country (ISO 3-letter code) |
| `year` | Year of observation |
| `extensive` | Number of subsidiaries |
| `OperatingrevenueTurnover` | Operating revenue |
| `Numberofemployees` | Number of employees |
| `TotalassetsthUSD` | Total assets |

## Data Processing

The original data is processed through an ETL workflow using **n8n** and subsequently stored in **MySQL** for further analysis.

The processing workflow includes:

1. Data extraction.
2. Data transformation and preparation.
3. Data loading into MySQL.
4. Data validation and consistency checks.
5. SQL analysis and Power BI visualization.

## Data Availability and Usage

This repository contains sample data, data documentation, and instructions on the original source.

Please consult the original USITC source and its applicable terms of use before downloading, redistributing, or publishing the complete dataset.
